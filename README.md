# Crypto Trading Terminal - Phase 1

Production-grade cryptocurrency algorithmic trading terminal with institutional-grade market analysis capabilities.

## Phase 1: Infrastructure Foundation

✅ Docker & Docker Compose
✅ PostgreSQL 15 + TimescaleDB
✅ Redis 7 Cache
✅ FastAPI Backend (Python 3.12)
✅ Next.js Frontend (React 18)
✅ Nginx Reverse Proxy
✅ Database Schema
✅ Binance API Client (CCXT)
✅ Data Ingestion Pipeline
✅ API Endpoints

## Quick Start

```bash
docker-compose up -d
```

## Access

- Frontend: http://localhost:3000
- API: http://localhost:8000
- Docs: http://localhost:8000/docs
- Health: http://localhost:8000/api/v1/health/alive

See PHASE_1_CHECKLIST.md for complete deliverables.
